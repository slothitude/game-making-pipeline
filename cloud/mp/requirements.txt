# cloud/mp (G3 skeleton) — single runtime dependency.
#
# aiohttp chosen over the `websockets` lib deliberately: it serves REST
# (/health, /lobby) and WS (/signal) on ONE port in one process, which is what
# Cloud Run wants. The lighter `websockets` lib was probed first (2026-09-23):
# its process_request hook cannot read a POST body, so REST /lobby was a
# non-starter there. aiohttp 3.9.1 is already the Rog install, so local ==
# container. wsproto was rejected — protocol-only, no HTTP layer (too raw per
# spec).
aiohttp>=3.9,<4
