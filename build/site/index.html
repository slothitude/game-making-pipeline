    The Pipeline's 3D expansion — a full procedural game engine that generates worlds, characters, and cinematics from text descriptions.

    🏗 World Generation
    LLM-authored world manifests (rooms, textures, lighting) → procedural 3D environments from JSON
    🎭 Character Creation
    TRELLIS.2 image-to-3D → rigged characters with BVH mocap animation → ready for any game
    🎬 Cinematic Rendering
    Blender headless with cel-shading and clay passes → animated cutscenes and title sequences
    🎨 Texture Pipeline
    HunyuanDiT + Flux → content-addressed texture work-orders → any surface, any style
    🤖 AI Animation
    BVH motion capture applied to generated meshes → walk, run, fight, idle — from a clips registry
