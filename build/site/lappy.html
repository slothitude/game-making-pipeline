THE STORY

Why a Shed?

Because that's where the laptop lives.

While tech companies spend millions on data centers, an autonomous game factory runs from a single RTX 3060 laptop sitting in a backyard shed in Cairns, Australia. It builds games, plays them, critiques them, and ships them — from the shed.

The brain is a cloud server in Sydney. The builder runs on GitHub Actions. The GPU work happens here, on this laptop, when it's not too hot in the shed. And the arcade is just... here. For anyone with a Telegram account.
