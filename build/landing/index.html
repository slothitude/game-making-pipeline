HOW IT WORKS

Every game keeps a diary — how it got made, the ideas, the sketches, the lore — updated at every milestone by the machine that made it. Every change to a live game must pass its own test wall before it ships: green twice in a row, or it doesn't deploy. The games talk back: an in-game FEEDBACK button sends your words straight into the Pipeline, and the next deployed build answers you.
